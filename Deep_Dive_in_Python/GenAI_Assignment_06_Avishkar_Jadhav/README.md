# Assignment 6: Exception Handling

## Objective
To understand and implement exception handling in Python using `try`, `except`, `else`, `finally`, and `raise`.

## Tasks

### Task 1: Safe Division Utility
Takes two numbers as input, handles invalid numeric input and division by zero, displays the result when successful, and always prints an operation completion message.

### Task 2: Bill Calculator
Processes a list of prices, handles non-numeric and negative prices, and calculates the running and final total.

### Task 3: Age Validator
Defines a `check_age()` function that raises a `ValueError` when the age is outside the range 1–120.

### Task 4: File Reader
Reads a user-specified file, handles missing-file and permission errors, displays the first three lines, and prints a completion message.

### Task 5: Safe Shopping Cart
Accepts item prices until the user enters `q`, handles invalid and negative prices, and displays the number of valid items and the final bill.

## Project Structure

- `task1_safe_division.py`
- `task2_bill_calculator.py`
- `task3_age_validator.py`
- `task4_file_reader.py`
- `task5_shopping_cart.py`
- `README.md`

## How to Run
Open a terminal in the project directory and run any task separately. For example:

```bash
python task1_safe_division.py
```

Replace the filename with the task you want to execute.
