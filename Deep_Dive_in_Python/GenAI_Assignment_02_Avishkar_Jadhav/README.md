# Assignment 2 - Python Control Flow

This assignment demonstrates the use of Python control flow concepts such as
conditionals, loops, break, and continue.

## Tasks

### Task 1 - Discount Rules
File: `Task_1/discount_rules.ipynb`

- Take order amount as input
- Apply discount based on order amount
- Calculate final amount
- Handle non-numeric input

### Task 2 - Multiple Orders
File: `Task_2/multiple_orders.ipynb`

- Process multiple orders
- Apply discount rules to each order
- Calculate total revenue
- Count discounted orders

### Task 3 - User Menu
File: `Task_3/user_menu.ipynb`

- Display a user menu
- Check balance
- Deposit money
- Withdraw money
- Continue showing the menu until Exit

### Task 4 - Loop Control
File: `Task_4/loop_control.ipynb`

- Process daily sales
- Use `continue` for zero-sales days
- Use `break` when corrupted data is found
- Calculate total sales

## How to Run

1. Open the project in VS Code.
2. Open any `.ipynb` file.
3. Select a Python Jupyter kernel.
4. Run the cells in order.

## Concepts Used

- `if`
- `elif`
- `else`
- `for` loops
- `while` loops
- `break`
- `continue`
- User input
- Basic arithmetic

## Requirements

The assignment uses basic Python and does not require external libraries.
