# Assignment 5: Importing, Creating Modules & Packages

## Objective
To understand Python modules, importing functions, and creating packages.

## Project Structure
- `main.py` — Main program demonstrating module and package imports.
- `math_utils.py` — Addition, subtraction, and square functions.
- `string_utils.py` — String capitalization, reversal, and word-count functions.
- `shop_package/discount.py` — Discount calculation functions.
- `shop_package/billing.py` — Billing and tax calculation functions.
- `shop_package/__init__.py` — Initializes the `shop_package` package.

## Concepts Covered
- Creating custom Python modules.
- Importing modules using `import module_name`.
- Importing specific functions using `from module_name import function_name`.
- Creating and importing Python packages.
- Using functions across multiple files.

## How to Run
Open a terminal in the project root directory and run:

```bash
python main.py
```
